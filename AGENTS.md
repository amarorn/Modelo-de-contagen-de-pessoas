# AGENTS.md

## Purpose
This file defines repository-specific instructions for coding agents working in this project.

## Project Setup
- Use the current working directory as the project root.
- Prefer fast file search tools when available.
- Keep changes minimal and focused on the requested task.

## Engineering Standards
- Preserve existing architecture and conventions.
- Avoid unrelated refactors.
- Add or update tests when behavior changes.
- Document non-obvious decisions in code comments or commit notes.

## Safety Rules
- Never run destructive git commands unless explicitly requested.
- Do not revert user-authored changes that are unrelated to the task.
- Confirm before making high-impact or irreversible changes.

## Delivery Checklist
- Verify the implementation locally when possible.
- Summarize changed files and rationale.
- Call out follow-up risks or TODOs if any remain.
